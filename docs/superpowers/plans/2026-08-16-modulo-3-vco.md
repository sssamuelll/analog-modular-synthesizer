**Goal:** Esquemático + PCB del módulo 3 (4 voces SSI2130, 3× AD5686R en cadena, telemetría I²C), generados por script con todos los gates del repo en verde, más bring-up documentado y los docs de arquitectura sincronizados.

**Architecture:** La placa se genera con el patrón del repo: `build_schematic.py` escribe el `.kicad_sch` directamente vía `hardware/tools/symlib.py` (SIN el servidor MCP — ya truncó una hoja una vez), con dos guardias propios antes de escribir (vértice de cable exacto en cada pin, y `schcheck.py` contra redes fusionadas), y verifica con `kicad-cli`. El PCB va con `pcbnew` directo (el Python de KiCad). Las 4 voces son un bucle en el generador, no cuatro copias.

**Tech Stack:** Python 3 + KiCad 10 (`kicad-cli`, `pcbnew`), `hardware/tools/{symlib,schcheck}.py`, `gh` para el ciclo PR.

**Spec:** `docs/superpowers/specs/2026-08-16-modulo-3-vco-design.md`

## Global Constraints

- **Referencia única ≤5 ppm/°C**: ADR4525**B**RZ (±0.02 %, 2 ppm/°C máx — verificado) alimenta el pin VREF de los 3 AD5686R (ref interna APAGADA por firmware, registro 0111) y de los 4 SSI2130.
- **Trimless**: cero trimmers. Span de pitch nominal ~7.5 octavas (margen ~7 %); `tuning.json` absorbe todo lo estático.
- **GNDA y GNDD no se tocan en el cobre de esta placa** — se unen solo en la estrella del módulo 1. Frontera medida por script, como módulo 2.
- **Regla de layout con aserción** (`dac_local_budget.py`): DACs pegados al racimo de SSI2130; el retorno del módulo no cruza el camino DAC→VCO.
- **VLOGIC de los DAC a +3.3 V**, nunca a 5 V (umbral VIH, lección del módulo 2).
- **Gates**: ERC 0, DRC 0, `check_netlist.py` y `check_bom.py` verdes, los cuatro `*_budget.py` del repo verdes.
- **V+ de los SSI2130 = +5 V regulado local** (máx absoluto 5.25 V — NUNCA conectar a +12 V). V− = −12 V directo.
- Nombres: proyecto `sam17-vco`, ficheros en `hardware/03-vco/kicad/`.
- Convención de commits del repo: mensaje en español que cuenta el porqué, con el trailer de coautoría de Claude.
- Datasheets primarios (obligatorio consultarlos, no de memoria): SSI2130 en `https://www.soundsemiconductor.com/downloads/ssi2130datasheet.pdf` (pinout pág. 4, Figure 1 pág. 5), AD5686R en `https://www.analog.com/media/en/technical-documentation/data-sheets/ad5686r_5685r_5684r.pdf` (DCEN pág. 21-23, ref setup pág. 26).

## Tabla maestra de redes (todas las tareas la usan)

| Red | Qué es |
|---|---|
| `+12V`, `-12V`, `GNDA`, `GNDD` | rieles del bus SAM17 (KK-254) |
| `+5V_LOC`, `+3V3_LOC` | regulación local |
| `VREF_2V5` | la ADR4525 — llega a 7 chips |
| `SPI_SCLK`, `SPI_MOSI`, `SPI_MISO`, `SPI_CS3` | enlace serie |
| `I2C_SDA`, `I2C_SCL` | telemetría |
| `DAC_LINK_12`, `DAC_LINK_23` | SDO→SDIN entre DACs de la cadena |
| `CV_PITCH_n` (n=1..4) | canal del DAC → nodo expo de la voz n |
| `CVIN_n` | punta del jack CV-IN de la voz n |
| `PWM_CV` | DAC → PWM− de los 4 chips |
| `MIX_SAW`, `MIX_TRI`, `MIX_PULSE`, `MIX_SINE` | DAC → controles de mezcla, compartidos |
| `TRI_n`, `SINEO_n`, `SQ_n`, `MIXO_n` | nodos de la voz n |
| `TUNE_OUT_n` | salida del 74HC14, voz n |
| `VOICE_OUT_n` | punta del jack de salida de la voz n |
