## Global Constraints

Copiadas de la spec §4 y de las enmiendas. Cada tarea las incluye implícitamente.

- **R-MJ1.** Ninguna transferencia del J2 en el cerebro corre con `TSIZE = 0`. `TSIZE` sale de `core::maestro_j2::Tsize` (`NonZeroU16`) y es el largo clocado de la cabecera §4, con relleno.
- **R-MJ2.** Ninguna espera del J2 es un bucle síncrono sin cota. Cotas escritas: `T_SUSP = 10 µs` (D4.3, ESTIMADO) y, desde hoy, `T_CANAL = 10 µs` para soltar los canales del GPDMA (enmienda del 18-09 a D4.2, #368). **Ningún `Transfer` de embassy se suelta (`Drop`) mientras su canal pueda estar corriendo.**
- **R-MJ3.** El reinicio sigue los ocho pasos de D4 en ese orden y cada paso cita su página. **Nunca se escribe a `TXDR` para desatascar** (fuera del control positivo, donde es el paliativo del hilo y se dice).
- **R-MJ4.** Los umbrales viven en `core::maestro_j2::Umbrales`; `fw` no copia ninguno.
- **R-MJ5.** Las tareas de ranura viven en el ejecutor del J2 (interrupción), no en el de hilo.
- **R-MJ6.** Una ranura sin identidad no se cloca ni se cuenta.
- **R-MJ7.** Búferes de DMA en memoria no cacheable o invalidados antes de leerse. **Hoy la D-cache del M55 está apagada** (embassy no la enciende: `grep enable_dcache` en la rev fijada, nada). El driver lo **asevera al arrancar**; el día que alguien la encienda, los búferes del J2 van a una región MPU propia (HUECO declarado, no de este plan).
- **R-MJ8.** `resistencia_j2.csv` con sus columnas: `ranura,instancia,tsize,nss,reloj_MHz,horas,giros,plazos_vencidos,eot_tardios,subidas_malas,fecha,placa`.
- **D2, orden de arranque enmendado el 11-09:** `SPE = 0 → TSIZE = N → RXDMAEN → canales de DMA armados → TXDMAEN → SPE = 1 → leer CR1 → esperar ≥ 1 T_SCK (en ciclos de CPU, no con embassy_time) → EOTC → EOTIE = 1 → CSTART`. El SPI queda **apagado** entre transferencias.
- **Todos los crates de embassy salen de la misma fuente** (`fw/Cargo.toml`, comentario de cabecera): git `sssamuelll/embassy`, rama `n6-usb`. Un crate nuevo de embassy (`embassy-sync`) entra con el mismo `git` y `branch`; nunca de crates.io.
- **La puerta de `fw` es `cargo build --release`** (enlaza; `check` no). La de `core` es `cargo test` + `cargo clippy --all-targets -- -D warnings` + `cargo fmt --check`. Las corre `.githooks/pre-push`.
- **Ningún número sin fuente.** Página del RM0486/ES0620/DS14791/UM3417, o `ESTIMADO` con la razón. Los AF de los pines: `af: 5` los ocho, del JSON del chip que usa embassy (`stm32-data-generated/data/chips/STM32N657X0.json`, verificado el 18-09) y de DS14791 Rev 10 Tabla 18.
- **Identificadores en español, sin acentos**, como el resto de `core` y `fw` (`giro`, `ranura`, `plazo`, `soltar`). Comentarios en español.
- **El montaje del banco** (EN-PLACA §«El J2 en la Nucleo», UM3417 Tabla 13): maestro **SPI5** (SCK PE15, MOSI PG2, MISO PG1, NSS PA3), esclavo **SPI4** (SCK PE2, MOSI PE14, MISO PE13, NSS PE11), los ocho en CN15, cuatro hilos. `SupplyConfig::External` **también vale para la Nucleo**: llega en configuración de SMPS externo por defecto (UM3417 §7.4.3, p. 20).

**La decisión (#368), razonada:** el `Drop` del `Transfer` de embassy (`gpdma/mod.rs:1287-1295`) hace `request_reset()` y `while is_running() {}`, sin cota. Si un canal del GPDMA no responde, la tarea que lo suelta se queda ahí con la interrupción del ejecutor del J2 ocupada: las otras cinco ranuras no corren, los seis módulos sueltan a los 50 ms y el IWDG reinicia el chip a mitad de concierto. Con el límite del 11-09 (cero artefactos audibles) eso no cabe. De las dos salidas del issue, la de «ejecutar el reinicio en una tarea fuera del ejecutor» no arregla nada: una espera que gire en cualquier ejecutor de interrupción bloquea al de hilo (pantalla, USB, MIDI), y en el de hilo bloquea todo lo demás. Lo que arregla es **que no haya espera sin cota**: el driver nunca suelta un `Transfer` mientras su canal pueda estar corriendo; pide el reset, **sondea `is_running()` como máximo `T_CANAL`**, y solo entonces lo suelta (el `Drop` entra y sale al instante). Si el canal no para, **escala**: olvida los dos `Transfer` (`core::mem::forget`, jamás girar) y resetea el GPDMA1 entero por RCC (`rcc::enable_and_reset::<GPDMA1>()`; el generador de embassy implementa `RccPeripheral` para `GPDMA1`, `_generated.rs:1594`). Consecuencia declarada: las otras cinco ranuras ven sus futuros de DMA resolverse con el canal parado, su `EOT` no llega, vence su plazo y ejecutan D4 cada una. Es un reinicio **de las seis ranuras bajo control**, dentro de los 50 ms del módulo, no un reinicio del chip. El IWDG queda como red solo para lo que ni un reset de RCC arregla, que por construcción no existe. `T_CANAL = 10 µs`, ESTIMADO como `T_SUSP`: la pausa de un canal del GPDMA actúa al fin de la ráfaga en curso (la tarea 7d cita la página del cap. del GPDMA del RM0486 al escribirlo).

**Qué encierra (spec D2, tres reglas):** (1) cada transferencia tiene una generación; un resultado se acepta solo si la generación coincide, y el que llega tarde se descarta **y se cuenta**; (2) el resultado guardado se borra al armar; (3) el waker se registra antes de mirar la bandera — esa es del futuro en `fw` (7c), no de aquí. La generación `0` significa «nunca armada»: `armar` nunca la devuelve.

```rust
use core::sync::atomic::{AtomicU32, Ordering};

/// Las banderas de `SR` que la ISR copia (D2): `EOT`, `SUSP`, `OVR`, `MODF`.
/// Un `u8` para que quepan en la palabra guardada del `Turno`.
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Banderas(u8);

impl Banderas {
    pub const NINGUNA: Banderas = Banderas(0);
    pub const EOT: Banderas = Banderas(1);
    pub const SUSP: Banderas = Banderas(2);
    pub const OVR: Banderas = Banderas(4);
    pub const MODF: Banderas = Banderas(8);
    pub const fn con(self, otra: Banderas) -> Banderas { Banderas(self.0 | otra.0) }
    pub const fn bits(self) -> u8 { self.0 }
    pub const fn de_bits(bits: u8) -> Banderas { Banderas(bits) }
    pub const fn eot(self) -> bool { self.0 & Self::EOT.0 != 0 }
    pub const fn susp(self) -> bool { self.0 & Self::SUSP.0 != 0 }
}

/// El turno de una transferencia: la generacion y el resultado guardado
/// (spec D2, reglas 1 y 2). Lo comparten la ISR y la tarea, por eso va con
/// atomicos y vive en un `static` de `fw`: la ISR `registra`, la tarea `arma`
/// y `toma`. La generacion 0 es "nunca armada".
///
/// `guardado` empaqueta en una palabra `VALIDO | generacion[22:0] << 8 |
/// banderas`, para que registrar y tomar sean un solo acceso atomico y no
/// haya lectura rota entre dos palabras.
pub struct Turno {
    generacion: AtomicU32,
    guardado: AtomicU32,
    tardios: AtomicU32,
}

const VALIDO: u32 = 1 << 31;
const MASCARA_GEN: u32 = (1 << 23) - 1;

impl Turno {
    pub const fn nuevo() -> Turno {
        Turno { generacion: AtomicU32::new(0), guardado: AtomicU32::new(0), tardios: AtomicU32::new(0) }
    }

    /// Nueva generacion (nunca 0) y borra lo guardado (regla 2). Devuelve la
    /// generacion y cuantos resultados se descartaron por tardios desde el
    /// armado anterior (regla 1): los que la ISR registro con una generacion
    /// que ya no era la armada, mas el que quedo guardado sin que la tarea
    /// lo tomara.
    pub fn armar(&self) -> (u32, u32) {
        let mut g = self.generacion.load(Ordering::Relaxed).wrapping_add(1);
        if g == 0 {
            g = 1;
        }
        self.generacion.store(g, Ordering::Release);
        let viejo = self.guardado.swap(0, Ordering::AcqRel);
        let sobrante = (viejo & VALIDO != 0) as u32;
        (g, self.tardios.swap(0, Ordering::AcqRel) + sobrante)
    }

    /// Desde la ISR. Guarda solo si `generacion` es la armada (regla 1); si
    /// no, lo cuenta como tardio y devuelve `false`.
    pub fn registrar(&self, generacion: u32, banderas: Banderas) -> bool {
        if generacion == 0 || generacion != self.generacion.load(Ordering::Acquire) {
            self.tardios.fetch_add(1, Ordering::AcqRel);
            return false;
        }
        let palabra = VALIDO | ((generacion & MASCARA_GEN) << 8) | banderas.bits() as u32;
        self.guardado.store(palabra, Ordering::Release);
        true
    }

    /// Desde la tarea. Devuelve y borra el resultado de la generacion armada.
    pub fn tomar(&self) -> Option<Banderas> {
        let armada = self.generacion.load(Ordering::Acquire) & MASCARA_GEN;
        let v = self.guardado.load(Ordering::Acquire);
        if v & VALIDO == 0 || (v >> 8) & MASCARA_GEN != armada {
            return None;
        }
        self.guardado.store(0, Ordering::Release);
        Some(Banderas::de_bits(v as u8))
    }

    pub fn generacion(&self) -> u32 {
        self.generacion.load(Ordering::Acquire)
    }
}
```

```rust
pub async fn giro(&mut self, bajada: &[u8], subida: &mut [u8], tsize: Tsize, plazo: Duration) -> (Resultado, u32) {
    let n = tsize.get() as usize;
    defmt::assert!(n <= bajada.len() && n <= subida.len() && n <= LARGO_MAX);
    let estado = &ESTADOS[self.indice];
    let (_gen, tardios) = estado.turno.armar();                         // D2 reglas 1-2

    regs.cr2().write(|w| w.set_tsize(tsize.get()));                       // D1: TSIZE = bytes clocados

    let mut rx = ManuallyDrop::new(unsafe { self.canal_rx.read(self.req_rx, self.rxdr, &mut subida[..n], TransferOptions::default()) });   // paso 2
    let mut tx = ManuallyDrop::new(unsafe { self.canal_tx.write(self.req_tx, &bajada[..n], self.txdr, TransferOptions::default()) });
    regs.cfg1().modify(|w| w.set_txdmaen(true));                          // paso 3
    regs.cr1().modify(|w| w.set_spe(true));                               // paso 4
    let _ = regs.cr1().read();                                            // anclaje (enmienda 11-09): la lectura vuelve cuando el periferico contesto
    cortex_m::asm::delay(self.ciclos_por_cuarto_tsck * self.retardo_cuartos as u32);   // >= 1 T_SCK en produccion; ES0396 §2.14.2 por analogia
    regs.ifcr().write(|w| w.set_eotc(true));                              // p. 3492: EOT puede ponerse al rehabilitar
    regs.ier().modify(|w| w.set_eotie(true));                             // p. 3490
    regs.cr1().modify(|w| w.set_cstart(true));
    let esperas = async {
        join(&mut *tx, &mut *rx).await;                                    // los dos DMA
        EsperaEot { estado }.await                                          // el EOT por EOTIE
    };
    match with_timeout(plazo, esperas).await {
        Ok(_banderas) => {
            // Los dos futuros de DMA resolvieron con el canal parado: el Drop entra y sale.
            unsafe { ManuallyDrop::drop(&mut tx); ManuallyDrop::drop(&mut rx); }
            regs.cr1().modify(|w| w.set_spe(false));                      // apagado entre transferencias (p. 3448, p. 3492)
            regs.cfg1().modify(|w| { w.set_txdmaen(false); w.set_rxdmaen(false); });   // cierre, paso 3 (p. 3451)
            (Resultado::Ok, tardios)
        }
        Err(_) => { self.reiniciar(tx, rx); (Resultado::PlazoVencido, tardios) }
    }
}
```

```rust
/// D4 paso 2 con cota (enmienda del 18-09, #368). Nunca gira sin cota: pide
/// el reset a los dos canales, sondea `is_running()` como maximo T_CANAL y solo
/// entonces los suelta (el Drop de embassy, gpdma/mod.rs:1287, entra y sale).
/// Si un canal no para, escala: olvida los dos Transfer y resetea el GPDMA1
/// entero por RCC. Las otras ranuras veran sus futuros resolverse, vencer su
/// plazo y ejecutar D4: un reinicio de las seis bajo control, no del chip.
pub fn soltar_canales(mut tx: ManuallyDrop<Transfer<'_>>, mut rx: ManuallyDrop<Transfer<'_>>) -> Soltado {
    tx.request_reset();
    rx.request_reset();
    let limite = Instant::now() + Duration::from_micros(T_CANAL_US);
    while tx.is_running() || rx.is_running() {
        if Instant::now() >= limite {
            core::mem::forget(tx);            // jamas dejar que su Drop gire
            core::mem::forget(rx);
            rcc::enable_and_reset::<peripherals::GPDMA1>();   // _generated.rs:1594
            ESCALADAS_GPDMA.fetch_add(1, Ordering::Relaxed);
            defmt::error!("D4.2: un canal del GPDMA no paro en {} us; GPDMA1 reseteado por RCC", T_CANAL_US);
            return Soltado::Escalado;
        }
    }
    unsafe { ManuallyDrop::drop(&mut tx); ManuallyDrop::drop(&mut rx); }
    Soltado::Limpio
}
```

```rust
async fn tarea_ranura(n: usize, mut ranura: Ranura<'static>, f_reloj_hz: u32, bajada_fn: Bajada, juez: Juez) {

    let mut bajada = [0u8; LARGO_MAX];
    let mut subida = [0u8; LARGO_MAX];
    let mut ticker = Ticker::every(Duration::from_micros(PERIODO_GIRO_US as u64));   // 8 kHz, spec §3
    loop {
        ticker.next().await;
        let tsize = bajada_fn(n, &mut bajada);
        SELLOS[n].fetch_add(1, Ordering::Relaxed);              // D5.4: al ARMAR
        let _ = politica.paso(Evento::Armada, ahora_us());
        let plazo = Duration::from_micros(plazo_us(tsize, f_reloj_hz, &umbrales) as u64);   // D3
        let (res, tardios) = ranura.giro(&bajada, &mut subida, tsize, plazo).await;
        for _ in 0..tardios { let _ = politica.paso(Evento::EotTardio, ahora_us()); }
        match res {
            Resultado::Ok => {
                let _ = politica.paso(Evento::GiroOk, ahora_us());
                let ev = if juez(n, &subida[..tsize.get() as usize]) { Evento::SubidaOk } else { Evento::SubidaMala };
                let _ = politica.paso(ev, ahora_us());
            }
            Resultado::PlazoVencido => {
                let accion = politica.paso(Evento::PlazoVencido, ahora_us());
                defmt::debug_assert!(accion == Accion::Reiniciar);   // D4 ya corrio dentro de giro; la politica y el transporte tienen que coincidir
            }
        }
        publicar_cuentas(n, &politica);
    }
}
```
