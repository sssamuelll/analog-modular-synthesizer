# Fuente v2 «GOAT» — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir el módulo `hardware/01-power-supply/v2/` completo — puertas de datasheet, esquemático generado, PCB con disciplina de islas, pipeline de fabricación JLCPCB con ensamblaje SMD y documentación de validación — hasta dejar la v2 lista para congelarse contra las medidas de la mula.

**Architecture:** Cascada de dos etapas por riel: pre-regulador ajustable TO-220-5 sobre disipador (LM2941CT → +13.1 V, LM2991T → −12.9 V) alimentando una pareja de LDO ultra-bajo-ruido en paralelo (LT3045 ×2 → +12.000 V, LT3094 ×2 → −12.000 V) con red SET compartida, ballast de 20 mΩ, sense Kelvin y masa de referencia en isla con un único puente. Todo lo demás (entrada 230 V, rectificación, bulk, 7805, crowbar, conectores) se hereda de la v1 sin tocar.

**Tech Stack:** Python 3 + `pcbnew` (KiCad 10), `kicad-cli`, `gh` CLI. Los generadores (`build_schematic.py` / `build_pcb.py`) y el cruce BOM↔hoja (`check_bom.py`) siguen el esqueleto exacto de la v1.

**Spec:** `docs/superpowers/specs/2026-08-16-psu-v2-goat-design.md` — el plan argumenta desde la spec; el ejecutor lee ambos. Léela ANTES de la primera tarea, junto con `hardware/01-power-supply/notes/design-notes.md` (v1) §13–§18.

## Global Constraints

- Rieles **±12.000 V a 650 mA/riel**; objetivo de ruido **0.8 µVrms (10 Hz–100 kHz)** — dato de datasheet, jamás se presume medido (spec §11.7).
- Placa **150×200 mm, 2 capas, FR-4 1.6 mm, cobre 1 oz**; mismos 4 NPTH M3 y misma ranura de barrera fresada (x=10…140, y=30…32) que la v1.
- **SMD en una sola cara (F.Cu)** — el ensamblaje a doble cara duplica coste.
- **Barrera de red ≥ 6 mm**; puente GND↔chasis único por el faston `J5` (v1 §13).
- **El silicio ultra se congela contra stock real de LCSC el día de mandar.** Si LT3045/LT3094 no tienen stock en ningún package: **STOP** — el plan B (TPS7A4701/TPS7A3301) tiene pinout distinto, no admite huella dual ni paralelo, y exige re-planificar. No se especula con el plan B en este plan.
- Todo número de datasheet usado para una decisión es el **garantizado (mín/máx), no el típico**, y lleva cita: fabricante, documento, revisión, página (lección v1 §16.1). Solo fuentes primarias (ti.com, analog.com, meanwell.com) — jamás agregadores.
- **ILIM ~800 mA/riel** (repartido por chip), **ballast 20 mΩ**, **una sola red SET por riel** (R=120 kΩ 0.1 %, C=22 µF baja fuga).
- Masa de referencia `GNDREF` (redes SET, OUTS, divisores) = isla unida a `GND` en **exactamente un punto** (`JP1`, net tie).
- Docs y comentarios en español, tono directo del repo. Commits con el trailer `Co-Authored-By` de sesión. **Una rama por fase, PR + merge al cierre de cada fase** (fases A–D marcadas abajo); lo aplazado se abre como issue con evidencia.

```python
def revisar_smd_cara(board) -> list[str]:
    males = []
    for fp in board.GetFootprints():
        if fp.GetAttributes() & pcbnew.FP_SMD and fp.GetLayer() != pcbnew.F_Cu:
            males.append(f"{fp.GetReference()} es SMD y no esta en F.Cu (ensamblaje una cara)")
    return males


def revisar_isla_referencia(board) -> list[str]:
    # GNDREF y GND solo se tocan dentro de JP1, y todo GNDREF vive en su isla.
    males, puentes = [], []
    for fp in board.GetFootprints():
        nets = {p.GetNetname() for p in fp.Pads()}
        if {"GNDREF", "GND"} <= nets:
            puentes.append(fp.GetReference())
    if puentes != ["JP1"]:
        males.append(f"puentes GNDREF-GND: {puentes} (debe ser exactamente ['JP1'])")
    x1, y1, x2, y2 = ISLA_REF
    for tr in board.GetTracks():
        if tr.GetNetname() == "GNDREF":
            for p in (tr.GetStart(), tr.GetEnd()):
                if not (mm(x1) <= p.x <= mm(x2) and mm(y1) <= p.y <= mm(y2)):
                    males.append(f"pista GNDREF fuera de la isla en ({p.x/1e6:.1f}, {p.y/1e6:.1f})")
    return males


def revisar_diagonal(board) -> list[str]:
    # El peor radiador (lazo de rectificacion) lejos de la isla ultra (spec sec.6.4).
    lazo = bbox_de(board, ["BR1", "C1", "C2", "C12", "C13"])
    ultra = bbox_de(board, ["U4", "U5", "U6", "U7", "R9", "R10", "C15", "C16"])
    d = distancia_bbox(lazo, ultra)
    return [] if d >= mm(80) else [f"lazo rectificador a {d/1e6:.0f} mm de la isla ultra (< 80)"]


def revisar_borde_ceramicos(board) -> list[str]:
    # Un ceramico es un microfono piezoelectrico en un cajon que vibra (spec sec.6.5).
    males = []
    borde = board.GetBoardEdgesBoundingBox()
    for ref in ["C15", "C16", "C23", "C24", "C25", "C26"]:
        fp = board.FindFootprintByReference(ref)
        b = fp.GetBoundingBox()
        margen = min(b.GetLeft() - borde.GetLeft(), borde.GetRight() - b.GetRight(),
                     b.GetTop() - borde.GetTop(), borde.GetBottom() - b.GetBottom())
        if margen < mm(10):
            males.append(f"{ref} a {margen/1e6:.1f} mm del borde (< 10)")
    return males
```

```python
"""Genera el BOM de ensamblaje JLCPCB desde bom.csv (filas con codigo LCSC)."""
import csv
import os
import sys

DIR = os.path.dirname(os.path.abspath(__file__))
SRC = os.path.join(DIR, "..", "bom.csv")
DST = os.path.join(DIR, "..", "fab", "sam17-power-v2-bom-jlc.csv")


def main() -> int:
    filas = []
    with open(SRC, newline="", encoding="utf-8") as fh:
        for row in csv.DictReader(fh):
            if row.get("lcsc", "").strip():
                filas.append({"Comment": row["value"], "Designator": row["refs"],
                              "Footprint": row["footprint"], "LCSC Part #": row["lcsc"]})
    if not filas:
        print("ninguna fila con codigo LCSC")
        return 1
    with open(DST, "w", newline="", encoding="utf-8") as fh:
        w = csv.DictWriter(fh, fieldnames=["Comment", "Designator", "Footprint", "LCSC Part #"])
        w.writeheader()
        w.writerows(filas)
    print(f"{len(filas)} lineas -> {DST}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
